# Financial Planner

See link to the [live project](https://github.com/sscales-dev/Finance-Planner).

This is a mini app based on my personal spreadsheet that I use to manage my finances

## User Experience (UX)

### Project Goals

**Rational:**

I have been using the Financial Planning Spreadsheet in its various forms for about 4-5 years and some of it's functionality would be much better suited to an app with a database, rather than using Google Sheets to manage the data.

I could tailor the UI to suit my needs and ensure it's just for me for now. It needs to be secure.

**Business Goals:**

Provide a user interface that the user can use effortlessly, within the remit of the task at hand (financial planning and management both on and between paydays)

**User Needs:**

- I need to be able to see all of my recurring transactions in a (variably sorted) list, and know how much they tally to for each payday
- I need to have a space to empty my head of income and expenditures I'm expecting to happen
- I need to have a clear picture of how my finances look, both now and in the future
- I need to be able to easily chop and change what expenses I include and don't include on each budget
- I need to be able to see all of my expected expenditures together, so that I can prioritise and consider the implications of when they go out.
- I need to be able to filter out expenditures depending on my needs at the time.
- I need a clear picture of what I'm paying to where on payday
- I need a space to think about, and see clearly, the various implications of my spending decisions

**Features to include:**

- Rolling, recurring budgets. Compprised of rolled-up planned income and expenditures
- Lists of my planned transactions, with all the relevant data enclosed in each record

**Future features:**

- current situation planner/ budgeting tool (see _now sheet in spreadsheet)

## Deployment

To run: set DEBUG=finance-planner:* & npm start

### GitHub Pages

I used GitHub Pages to deploy my project, using the steps as follows:

1. Navigate to 'Settings' tab at top of repository
1. Scroll to bottom of 'General' page and click 'Change Visibility' > 'Change to Public'
1. Click 'I want to make my repository public'
1. Click 'I have read and understand these effects'
1. Click 'Make This Respository Public'

1. Choose 'Pages' from left-hand menu in Settings
1. Under 'Build and deployment' > 'Branch', choose the source 'main' from the dropdown menu
1. Click 'Save' (to the right of '/ (root)')
